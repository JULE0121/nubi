# 개발 순서

현재 완료 범위는 프로젝트 기본 구조와 Git 설정입니다.

| 단계 | 작업 | 결과물 |
|---|---|---|
| 01 | Python·Git·KNIME 환경 확인 | 개발 환경 |
| 02 | 폴더·Git 설정 | 프로젝트 구조와 변경 기록 |
| 03 | 관광지·날씨·방문객 데이터 수집·정리 | 출처 있는 원본 CSV |
| 04 | KNIME 날씨 적합도 분석 | 적합도 데이터 |
| 05 | KNIME 관광지 유사도 분석 | 유사 관광지 후보 |
| 06 | 추천 알고리즘 구현 | Python 함수·결과 CSV |
| 07 | Streamlit 화면 | 입력·수정·추천 화면 |
| 08 | GPT 일정 인식 연동 | 날짜·시간·장소 추출 |
| 09 | 날씨 API 연동 | 예보 기반 적합도 |
| 10 | 지도 API 연동 | 위치·거리·동선 |
| 11 | GPT 일정 재구성 | 변경 일정과 이유 |
| 12 | 통합 테스트·발표 | 검증 결과·시연·발표자료 |

AI가 인식한 일정은 사용자가 확인·수정한 뒤 추천에 사용합니다. 분석 기준과 추천 가중치는 데이터로 검토하며, 미조회 정보는 사실처럼 제시하지 않습니다.
