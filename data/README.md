# 데이터 관리

`raw/`에는 원본, `processed/`에는 정리·분석 결과를 보관합니다. 현재는 월별 날씨 초안과 테마 유사도 자료가 있습니다.
자료마다 출처 URL, 수집일, 이용 조건, 지역·기간·집계 단위, 결측치 처리 방법을 기록합니다. 관광지는 공통 장소 ID로 연결합니다.
개인정보와 API 키는 데이터 파일에 넣지 않습니다. 큰 원본 파일은 커밋 전에 저장 방식을 결정합니다.

## 추천에 사용하는 파일

- `processed/weather_suitability_monthly_draft.csv`: 관광지 323곳의 월별 날씨 규칙 검증용 자료입니다. 실시간 예보가 아닙니다.
- `processed/theme_similarity.csv`: 6개 테마끼리 비교하는 0~1 점수표입니다. 추천 코드에서 읽습니다.
- `processed/theme_similarity_pairs.csv`: 테마 조합별 점수와 정한 이유를 정리한 자료입니다.

테마 점수는 현재 추천을 시험하기 위한 초기 기준입니다. 실제 사용자 평가나 학습으로 검증된 점수는 아니며, 추천 결과를 확인하면서 조정할 예정입니다.
